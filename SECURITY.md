# Politique de sécurité

## Versions prises en charge

Seule la dernière version publiée est maintenue avec des correctifs de sécurité.

## Signaler une vulnérabilité

Utiliser de préférence les **private vulnerability reports** de GitHub dans l’onglet Security du dépôt. Ne pas ouvrir d’issue publique avant correction.

Inclure :

- la version ou le digest de l’image concernée ;
- les étapes de reproduction ;
- l’impact estimé ;
- une proposition de correction si disponible.

Ne transmettre aucune donnée de patient, donnée personnelle ou information issue d’un système hospitalier réel.

Un premier accusé de réception est visé sous cinq jours ouvrés. La publication coordonnée intervient après disponibilité d’un correctif.
